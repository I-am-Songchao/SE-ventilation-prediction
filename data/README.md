# `data/`

No patient-level source data are distributed with this repository.

MIMIC-IV and eICU-CRD are credentialed research databases available through PhysioNet. Users must obtain independent access authorization and comply with the applicable data-use agreements.

This directory may contain only non-sensitive example files, synthetic demonstration data, data dictionaries, or empty templates if needed for reproducibility.

Do not commit patient-level MIMIC-IV or eICU-CRD data, identifiers, restricted analysis cohorts, credentials, or authentication tokens.
